Supported file format: .xlsx

Excel Column Format

The first row of your Excel sheet should contain the column headings shown below.

Name Phone Number Details
Fazlu 9876543210 Interested in AI training
Rahman 8123456789 Working professional
Required columns: Name and Phone Number.
Optional column: Details.

Accepted Column Names

Name: Name, Lead Name, Customer Name, Full Name
Phone: Phone Number, Phone, Mobile, Mobile Number, Contact Number
Details: Details, Notes, Remarks, Description

What happens during import?

✓ Valid leads are added with PENDING status.
✓ Duplicate phone numbers are skipped.
✓ Duplicate numbers inside the same Excel file are also skipped.
✓ Rows without a name or phone number are skipped.
✓ Invalid phone numbers are skipped.
✓ Existing Call Sessions are not changed.
